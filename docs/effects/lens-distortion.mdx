---
title: LensDistortion
nav: 1
---

A radial lens distortion effect. Positive `distortion` values give a barrel (fisheye-like) look, negative values a pincushion look.

```jsx
import { LensDistortion } from '@react-three/postprocessing'

return (
  <LensDistortion
    distortion={[0.5, 0.5]} // radial distortion coefficients
    principalPoint={[0, 0]} // center offset
    focalLength={[0.7, 0.7]} // lower values zoom in, hiding the black corners
    skew={0} // skew in radians
  />
)
```

## Props

| Name           | Type    | Default | Description                             |
| -------------- | ------- | ------- | --------------------------------------- |
| distortion     | Vector2 | [0, 0]  | The radial distortion coefficients.     |
| principalPoint | Vector2 | [0, 0]  | The center point offset.                |
| focalLength    | Vector2 | [1, 1]  | The focal length. Lower values zoom in. |
| skew           | Number  | 0       | The skew factor in radians.             |
