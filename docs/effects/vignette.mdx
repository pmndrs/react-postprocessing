A vignette effect.

```jsx
import { Vignette } from '@react-three/postprocessing'
import { BlendFunction } from 'postprocessing'

return (
  <Vignette
    offset={0.5} // vignette offset
    darkness={0.5} // vignette darkness
    eskil={false} // Eskil's vignette technique
    blendFunction={BlendFunction.NORMAL} // blend mode
  />
)
```

## Example

[![Vignette demo](https://pmndrs.github.io/examples/vignette/thumbnail.webp)](https://pmndrs.github.io/examples/vignette)

## Props

| Name          | Type              | Default                   | Description                          |
| ------------- | ----------------- | ------------------------- | ------------------------------------ |
| eskil         | Boolean           | false                     | Deprecated. Use `technique` instead. |
| blendFunction | BlendFunction     | BlendFunction.NORMAL      | The blend function of this effect.   |
| offset        | Number            | 0.5                       | The vignette offset.                 |
| darkness      | Number            | 0.5                       | The vignette darkness.               |
| technique     | VignetteTechnique | VignetteTechnique.DEFAULT | The vignette technique.              |
| opacity       | Number            | 1                         | The opacity of this effect.          |
